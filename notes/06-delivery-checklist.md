# 06 — Delivery Checklist

## Requirements
- [ ] Search input/output explicitly defined
- [ ] Dataset schema and missing-data handling documented
- [ ] Functional search with classification/title/abstract hybrid filters
- [ ] Runtime comparison with and without hybrid filters
- [ ] Scalability design for ~10 million patents
- [ ] Components/pipelines/errors/status/cost breakdown included
- [ ] One at-scale design PoC implemented
- [ ] Exactly one Part 3 enhancement implemented
- [ ] Enhancement's required evaluation/measurement documented

## Reproducibility
- [ ] Exact setup/install commands in root README
- [ ] Exact commands to ingest/index data
- [ ] Exact command to run search/API/UI and tests
- [ ] Any external keys/models are disclosed; no secrets committed
- [ ] Sample command/query that reviewers can reproduce
- [ ] Benchmark methodology and measured figures included

## Submission
- [ ] GitHub repository link accessible
- [ ] README: selected problem, approach, enhancement and why, reproduction
- [ ] Short ~2-minute recording addresses Part 2 and Part 3
- [ ] Video link accessible without a school-only account
- [ ] Notes and diagrams are easy to find but don't substitute for runnable code
