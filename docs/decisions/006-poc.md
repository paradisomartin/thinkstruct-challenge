# D-006 — Part 2 proof of concept

**Status:** Selected and locally verified · **Date:** 2026-11-16.

After explicit selection, the Part 2 PoC runs ingestion/indexing as disposable
containers and serves persisted results from the same image in a separate API
container. It reuses Part 1 commands rather than introducing a queue.

A Compose override removes the code bind mount and uses an isolated database
volume and port. The recorded clean-start check covered migrations, 640 indexed
patents, idempotent reimport, SQL counts, HTTP filters and the 55-test suite.
[Commands and evidence](../architecture/part-2-poc.md).

Status tracking was an alternative, not implemented. This PoC demonstrates local
containerization, not ECS/S3 integration or throughput at scale.
